# Magnet Studio

Standalone internal tool for creating English client briefs and social media reports.

- No connection to Magnet OS, Supabase, production data, or authentication.
- Drafts are stored only in the current browser using `localStorage`.
- PDF export uses the browser print dialog. Choose **Save as PDF** and enable **Background graphics**.

Open `magnet-studio/index.html` directly, or serve the repository root locally and visit `/magnet-studio/`.
